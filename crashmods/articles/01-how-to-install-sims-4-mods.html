How to Install Sims 4 Mods and CC: The Mods Folder, Settings and Fixes

Installing custom content in The Sims 4 takes three steps: put the files in the right folder, switch mods on in the game options, and restart. Most "my CC isn't showing up" problems come from skipping one of those steps or from a script mod sitting one folder too deep. This guide covers all of it on Windows and Mac, plus what to do after a game patch turns your mods off.

Where is the Sims 4 Mods folder?

The game keeps mods in your user Documents folder, not in the install folder. It is the same whether you play through the EA app or Steam:

  • Windows: Documents\Electronic Arts\The Sims 4\Mods
  • Mac: Documents/Electronic Arts/The Sims 4/Mods

The game creates this folder the first time it starts. If you cannot find it, launch The Sims 4 once, reach the main menu, then quit and look again. Inside you will find a file called Resource.cfg. Leave it there: it tells the game how deep to look for your files.

Step 1: Know which files go where

Almost everything you download is one of two file types:

  • .package files are custom content (hair, clothes, objects) and most tuning mods. They go in the Mods folder.
  • .ts4script files are script mods that change how the game behaves. They also go in the Mods folder, usually next to a .package file with the same name.

Downloads often arrive as a .zip or .rar archive. Extract it and move the .package and .ts4script files into Mods. Do not try to unzip a .ts4script file itself: the game reads it as it is.

Saved Sims, households and lots work differently. Files ending in .trayitem, along with the files that come with them, belong in the Tray folder next to Mods. They then show up in the Gallery under "My Library".

Step 2: Keep script mods one folder deep

You can sort CC into subfolders, which makes a large collection much easier to manage. The limits are different for the two file types:

  • .package files can sit up to five subfolders deep.
  • .ts4script files work only directly in Mods or one subfolder below it.

So Mods/Gameplay/modname.ts4script works, but Mods/Gameplay/Careers/modname.ts4script does not. A script mod that is too deep simply never loads, and the game gives no warning about it. This is the most common reason a gameplay mod "does nothing".

Step 3: Turn on mods in the game options

  1. Start The Sims 4 and open Game Options from the menu.
  2. Go to the Other tab.
  3. Tick Enable Custom Content and Mods.
  4. Tick Script Mods Allowed if you use any .ts4script mods.
  5. Click Apply Changes, then quit and restart the game.

After the restart, the game lists the mods it found in a pop-up. Hair and clothing then appear in Create a Sim, and objects in Build Mode.

After every game patch

When The Sims 4 updates, it switches mods off on purpose, because older script mods can break with a new patch. After an update:

  1. Check your script mods' download pages for updated versions and replace the old files.
  2. Delete localthumbcache.package from the The Sims 4 folder (one level above Mods). The game rebuilds it on the next start.
  3. Turn mods back on under Game Options → Other and restart.

Plain CC like hair and clothing rarely breaks after a patch. Script mods are the ones to check.

Sims 4 mods not working? Check these first

  • Mods are switched off. Look in Game Options → Other. A patch may have turned them off again.
  • Script mod too deep. Move the .ts4script file up so it is at most one subfolder inside Mods.
  • Files still zipped. The game cannot read .zip or .rar archives. Extract them first.
  • Outdated script mod. Download the version made for the current patch.
  • Old cache. Delete localthumbcache.package after you add or remove mods.
  • Two mods change the same thing. Remove one of them, or use the 50/50 method below.

The 50/50 method for finding a broken mod

Move half of your Mods folder to the desktop and test the game. If the problem is gone, the broken file is in the half you moved. Put that half back, move half of it out again, and repeat. Even with thousands of files, a few rounds narrow it down to one mod.

Can you use mods on PS5 or Xbox?

No. Custom content and script mods only work on the PC and Mac versions of The Sims 4. Console players can use the in-game Gallery, but not downloaded mods.
